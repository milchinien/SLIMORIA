# Prototypen

Spielwiese fuer Experimente — unabhaengig vom eigentlichen Spiel.

Hier landet alles, was ausprobiert, aber (noch) nicht ins Spiel uebernommen wird:
Bewegungs-Tests, Kampfsystem-Skizzen, Shader-Versuche, Balancing-Rechnereien.

**Regeln:**
- Pro Experiment ein eigener Unterordner, z. B. `prototypen/slime-bewegung/`.
- Nichts hier drin wird vom richtigen Spiel importiert — die Abhaengigkeit
  geht nur in eine Richtung: Prototyp -> (bei Erfolg) Code ins Spiel kopieren.
- Darf ruhig unaufgeraeumt sein. Kaputte Prototypen einfach loeschen.
